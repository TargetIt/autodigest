# autodigest

`autodigest` 是一个用于学习复杂概念的自动消化仓库。

它的目标不是把材料整理成一组形式完整的笔记，而是先把一个知识对象真正讲清楚，再按需要扩展成文章、指南、图解或演讲稿。默认输出中文内容。

## 核心原则

默认不再一次性生成十篇视角文章。十个视角是工具箱，不是必填表。

一次认真消化先完成这条主线：

1. 收集原始材料，并明确资料边界。
2. 建立源信息账本，区分事实、主张、机制、例子、条件和开放问题。
3. 找出真正难懂、容易误解或最影响判断的地方。
4. 写一篇高质量核心解释，把问题、机制、例子和边界讲通。
5. 用最小例子、反例和连续追问修复核心解释。
6. 只选择能带来新增理解的视角扩展，不合适的视角明确跳过。
7. 检视忠实度、一致性和未解决问题。
8. 最后再整理成可复用输出。

## 仓库结构

```text
autodigest/
  inbox/       临时材料、链接、摘录、想法。
  sources/     书、论文、视频、文档、代码、课程等源材料记录。
  digests/     按主题分目录保存源账本、核心解释、例子、反例、追问和视角扩展。
  concepts/    可复用概念页、定义、模型、区分。
  outputs/     最终产出：文章、学习指南、图解、演讲稿等。
  prompts/     AI 辅助消化提示词。
  scripts/     小型本地自动化脚本。
  templates/   中文 Markdown 模板。
  workflows/   固定 Auto Digest 工作流。
```

## 默认消化包

创建一个新消化包：

```bash
python3 scripts/new_digest.py "Transformer Attention"
```

脚本会生成：

- `sources/<主题>.md`
- `concepts/<主题>.md`
- `digests/<主题>/00-源信息账本.md`
- `digests/<主题>/01-核心解释.md`
- `digests/<主题>/02-最小例子.md`
- `digests/<主题>/03-误解与反例.md`
- `digests/<主题>/04-追问修复.md`
- `digests/<主题>/05-可选视角扩展.md`
- `digests/<主题>/06-检视记录.md`
- `digests/<主题>/07-最终输出草稿.md`

目录示例：

```text
digests/
  transformer-attention/
    00-源信息账本.md
    01-核心解释.md
    02-最小例子.md
    03-误解与反例.md
    04-追问修复.md
    05-可选视角扩展.md
    06-检视记录.md
    07-最终输出草稿.md
```

`templates/articles/` 仍然保留十个传统视角模板。需要时可以手动复制或让模型按 `05-可选视角扩展.md` 中选出的视角生成。

## 质量标准

每次消化必须回答：

- 这个东西解决什么核心问题？
- 它最容易被误解成什么？
- 它由哪些必要部分组成？
- 这些部分怎样交互，形成什么机制？
- 最小可运行或可观察例子是什么？
- 哪个反例能说明它不是什么、何时不成立？
- 如果连续追问“为什么”，解释在哪里会卡住？
- 学会它以后，人的判断或行动能力发生什么变化？

每次认真消化还必须完成：

- 源材料忠实度检视。
- 核心解释的跳步、术语依赖和边界检视。
- 最小例子与核心机制的一致性检视。
- 反例是否真正校准边界的检视。
- 可选视角是否带来新增理解的检视。
- 未确认信息标注为“待确认”或“开放问题”。

## 使用建议

不要让大模型一轮生成全部内容。推荐分轮：

1. 只整理源信息账本和理解难点。
2. 只写核心解释。
3. 只用例子、反例和追问修复核心解释。
4. 只选择并生成最有价值的视角扩展。
5. 最后检视并整理最终输出。

这样可以避免模型为了满足模板而牺牲内容深度。
