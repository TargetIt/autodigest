# Digest Prompt

Use this prompt when processing a complex source.

```text
I am learning the following material:

[paste source excerpt, notes, link summary, or transcript segment]

Help me digest it using this structure:

1. State the core problem in plain language.
2. Extract the key claims.
3. Identify the concepts I must understand.
4. Explain the mechanism step by step.
5. Give one concrete example.
6. List likely misconceptions.
7. Ask me 3 questions that test whether I really understand it.
8. Suggest what should become a source note, digest note, concept note, or output.

Write in Chinese unless the source terminology is better kept in English.
```
