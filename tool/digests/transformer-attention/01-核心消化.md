## 轻量源信息账本

- S1 [原文 §3.2.1] 定义：Attention(Q,K,V) = softmax(QKᵀ/√d_k)V，三个输入分别叫 query、key、value。
- S2 [原文 §3.2.1 脚注] 机制：除以 √d_k 是因为 d_k 很大时点积的量级变大，会把 softmax 推进梯度极小的饱和区。
- S3 [原文 §3.2.2] 机制：多头 = h 个并行头，各在 d_k=d_v=d_model/h 的子空间做注意力，拼接后经 W_O 投影；总计算量与单头全维相当。
- S4 [原文 §3.2.2] 机制：解码器的自注意力加 mask，把非法位置（未来位置）置 -∞ 再进 softmax。
- S5 [原文 §3.5] 机制：位置编码 PE(pos,2i)=sin(pos/10000^(2i/d_model))、PE(pos,2i+1)=cos(pos/10000^(2i/d_model))；对固定偏移 k，PE(pos+k) 是 PE(pos) 的线性函数，模型可以利用相对位置。

- S7 [原文 §3.2.2] 主张：当序列长度 n 小于表示维度 d（机器翻译的典型情形）时，自注意力每层比循环层更快。
- S8 [原文 §6.4] 主张：论文观察到不同注意力头呈现与句法结构（如回指消解）和语义相关的行为。
- S9 [原文摘要、§5] 数据：WMT14 英德 28.4 BLEU（超越当时最优集成模型 2 个点以上）、英法 41.8 BLEU；base 模型 8 块 P100 训练 12 小时，big 模型 3.5 天。

## 理解难点

1. （对应 Q1）「attention」这个词自带「目光、注视」的隐喻，让人以为有什么东西在扫描句子。实际上 Q/K/V 不是三个分开存放的东西，而是同一个 token 向量被三个可学习矩阵投影后的三份拷贝。难在把「名词的隐喻」换成「加权求和的机制」。
2. （对应 Q2）√d_k 与「注意力」的语义无关，是纯数值稳定工程。难在直觉上「除以一个常数」这种小动作值得单独一问，但它决定训练能不能学得动。
3. （对应 Q3）「多头」听起来像 8 个工人做同样的事。难在理解：每个头在自己的低维子空间里独立度量相关性，学出的是不同类型的关系；单头大维也可以，但所有关系类型被硬塞进同一个空间。
4. （对应 Q4）公式里完全没有位置概念，全部位置同时处理。注意力对输入是置换等变的 [推导]——「狗 咬 人」和「人 咬 狗」的词向量输出除了排列顺序外完全相同。顺序信息 100% 靠位置编码从外部注入。这个反直觉的事实是理解注意力的钥匙。
5. （对应 Q5）「适不适合」不是一句口号，要把 Table 1 的三把尺子变成可操作的问题：序列有多长（n² 配对算得起吗）、需要多远的信息路径（O(1) 值不值这个代价）、有没有顺序要求（位置编码设计好了吗）。

## 核心解释

### 一句话理解

自注意力是让序列里每个位置，用「我要找什么（Q）、我贴着什么标签（K）、我携带什么内容（V）」三份投影，动态算出该从其他每个位置各拿多少内容的加权求和机制。注意力和「注视」无关，它是相关性加权的内容搬运；前提是它本身对顺序完全无感，顺序必须由位置编码从外部注入。

### 它解决什么问题

在注意力之前，序列建模靠 RNN 或 CNN。RNN 的信息路径是 O(n)：第 1 个词的信息要传到第 1000 个词，必须经过 999 次状态传递，每一步都有遗忘和梯度衰减的压力；CNN 靠感受野逐层扩大，路径是 O(log_k n)，要堆很多层才能让远距离的词互相看见 [原文:S6]。

自注意力把任意两个位置的最大路径长度压到 O(1)：第 1 个词和第 1000 个词之间不再隔着任何传递过程，它们直接被放进同一轮配对计算。代价是把「路程」换成了「配对」：每层要算全部 n² 个位置对，复杂度 O(n²·d) [原文:S6]。当 n 不太大（机器翻译里 n 通常远小于 d [原文:S7]）时，这笔买卖很划算。

### 机制正文

**先建立一个检索直觉，然后立刻给它打两个补丁。**

想象你在书库找资料。你心里有一个检索词（query），每本书书脊上贴着标签（key），你拿检索词和每本书的标签做匹配度打分，分数越高越该看；然后把匹配度归一化成「从这本书摘抄的比例」（softmax）；每本书的内容是 value；最后输出 = 所有书的内容按比例加权求和。

这个比喻走通了大半个机制，但有两个地方必须立刻纠正，否则会学歪 [类比，边界见下]：

**补丁一：Q、K、V 不是三个分开存的东西。** 序列里每个 token 向量 x，分别乘上三个可学习的矩阵 W_Q、W_K、W_V，得到三份投影 Q=xW_Q、K=xW_K、V=xW_V。同一个 x，只是投影方向不同。矩阵是学出来的：W_Q 学「按什么标准衡量我要找什么」，W_K 学「按什么标准展示我的标签」，W_V 学「携带哪些内容供人搬运」。

**补丁二：为什么点积能当「匹配度」。** 两个向量方向越接近，点积越大——它是余弦相似度的未归一化版本。而 W_Q、W_K 存在的意义，就是把原始 embedding 里与「相关性」无关的维度压掉，让点积只度量该度量的东西 [解释]。

**数值过程，四步（每步都能心算）：**

1. 投影：Q = XW_Q，K = XW_K，V = XW_V。X 是 n×d_model，投影后 Q、K 是 n×d_k，V 是 n×d_v。
2. 打分：S = QKᵀ，得到 n×n 的分数矩阵，S[i][j] = 位置 i 的 query 与位置 j 的 key 的点积，即「i 觉得 j 有多相关」。
3. 归一化：先除以 √d_k，再对每一行做 softmax，得到 n×n 权重矩阵，每行和为 1。
4. 搬运：输出 = 权重 × V。每个位置的输出，都是全部位置 value 的凸组合（权重非负、和为 1）——这保证输出的量级自动稳定，也让它可解释成「注意力分配」。

**为什么要除以 √d_k。** d_k 越大，点积是越多项的和，绝对值天然越大；分数一大，softmax 就把它们挤向 0 和 1 两个极端（饱和区），而 softmax 在那里的梯度几乎为 0——模型学不动了 [原文:S2]。除以 √d_k 把分数的尺度压回适中，是数值稳定的工程设计，不是语义需要 [原文:S2 + 解释]。不除的直接后果就是训练不稳、学不动（对应 Q2 的「不除会怎样」）。

**多头到底多在哪里。** 多头 = 8 套独立的 W_Q/W_K/W_V，各自在 d_k=64 的子空间里做一遍上述四步，把 8 份输出拼接起来，再过一次 W_O 投影融合 [原文:S3]。它的价值不在于「算 8 遍」，而在于**论文观察到不同头呈现与不同语言结构相关的行为**：有的头看起来在做回指消解，有的头与句法/语义关系相关 [原文:S8]。多头让这些关系各占一个子空间，不必挤在一起 [解释]。单头全维当然也能算注意力，但所有类型的关系要挤进同一个投影空间，投影矩阵被迫折中，什么关系都只能抓到一点 [解释]。多头相当于把「关系空间」切成 8 份，让每个投影各管一摊 [类比]。代价是计算量不省：8 头 × 64 维 ≈ 1 头 × 512 维 [原文:S3]。

**顺序信息从哪来：位置编码。** 把公式摊开看：如果打乱输入序列的行序，Q、K、V 的行跟着一起换，分数矩阵的行列跟着换，softmax 和加权求和只是「跟着换」，每个位置拿到的信息内容一模一样——注意力对输入是置换等变的 [推导]。所以「狗 咬 人」和「人 咬 狗」在纯注意力眼里没有区别。原文的解法是在 token 向量进注意力之前，先加上一个只由位置决定的向量 PE(pos)，让「位置 3 的狗」和「位置 1 的狗」从一开始就是不同的向量 [原文:S5]。

正弦编码的设计值得多看一眼：d_model=4 时，位置 0 是 [sin0, cos0, sin0, cos0] = [0, 1, 0, 1]；位置 1 是 [sin1, cos1, sin(1/100), cos(1/100)] ≈ [0.84, 0.54, 0.01, 1.00]。前两个维度频率高（相邻位置差异大，能区分局部次序），后两个维度频率低（变化慢，能标记远距离波段）。更妙的是：对任何固定偏移 k，PE(pos+k) 都是 PE(pos) 的线性函数 [原文:S5]——模型靠学一个线性变换就能「平移」位置信息，相对位置关系是被编码结构直接支持的。

**解码器的一个细节：mask。** 自回归生成时，位置 i 不允许看到 i 之后的内容。做法是打分时把非法位置的分数量成 -∞，softmax(-∞)=0，那些位置的权重自动归零 [原文:S4]。这不是自注意力特有的，但它是理解「GPT 类模型为什么只能往前看」的关键一行。

### 一个具体例子（全部可心算）

取 d_model=4、单头、d_k=4，两个 token：x₁=[1,0,1,0]，x₂=[0,1,0,1]。为了心算，让 W_Q=W_K=W_V=单位矩阵（即 Q=K=V=X）[省略说明见下]。

打分：S = QKᵀ = x₁x₁ᵀ=2、x₁x₂ᵀ=0、x₂x₁ᵀ=0、x₂x₂ᵀ=2，即 S=[[2,0],[0,2]]。两个 token 互相正交，所以匹配度是「自己 2、对方 0」——点积就是在这个例子里「度量方向一致性」的具体样子。

缩放：除以 √d_k=√4=2，S'=[[1,0],[0,1]]。

softmax 按行归一：e/(e+1)≈0.73，1/(e+1)≈0.27。权重矩阵 W=[[0.73,0.27],[0.27,0.73]]。

搬运：第 1 行输出 = 0.73·x₁ + 0.27·x₂ = [0.73, 0.27, 0.73, 0.27]；第 2 行输出 = 0.27·x₁ + 0.73·x₂ = [0.27, 0.73, 0.27, 0.73]。

读出来的机制：每个位置的输出主要是自己、混入少量对方——两个向量被「注意力」互相搬了一部分内容，搬多少由匹配度决定。

同一套数字做两个变体，各回答一个问题：

- **变体一（Q4 的直观证明）：** 把两个 token 对调，Q/K/V 的行对调，权重矩阵跟着对调，输出行跟着对调——每行的内容不变。没有位置编码时，「我 爱」和「爱 我」的隐藏表示完全相同，只是行序不同。这就是为什么必须加 PE。
- **变体二（mask 的直观证明）：** 解码器里把 S[0][1] 置 -∞，softmax 后权重行变成 [1, 0]，第 1 行输出 = 1·x₁ + 0·x₂ = x₁——位置 1 完全看不到位置 2。

**这个例子省略了什么：** W 不是学出来的（单位矩阵）、没有多头、d_model=4 远小于真实的 512、只有 2 个 token 而真实是 n×n 权重矩阵。**为什么这些省略不歪曲原理：** 核心机制链（投影→点积打分→缩放→softmax 行归一→加权搬运）一步不缺地跑通了，省掉的都是「规模」而不是「机制」。

### 它不是什么 / 不成立条件

- 它不是「理解语义」：权重是数据驱动的匹配度，不是意义判断 [解释]。两个词注意力权重高，只说明在训练数据里它们常相关。
- 它不是顺序模型：置换等变 [推导]，顺序全靠位置编码。没有 PE 的注意力处理不了任何顺序敏感的任务。
- 它不是记忆：注意力本身没有参数化存储，权重是当场算出来的，用完即弃 [解释]。
- 它不擅长超长序列：n² 个配对的计算和 n² 权重矩阵的存储都是实打实的开销。
- mask 之后它不能看未来：自回归场景里这是特性，做双向理解时是限制。
- 适用条件：n 不太大（n² 可承受）且 d 相对大时，它的 O(1) 路径长度才值得花 O(n²·d) 去买 [原文:S6/S7]。

### 普通中文重建（不看原文）

一个句子进来，每个词都先变成向量。然后每个词干三件事：用一个学好的矩阵问「我想找什么」（Q）；用另一个学好的矩阵给全句发自己的标签（K）；再用一个学好的矩阵把自己的内容打包（V）。接着每个词拿自己的 Q 和全句所有 K 做点积，得到一个「我和每个词有多相关」的分数表；把分数除以一个数压一压，再归一化成百分比；最后按这个百分比把全句的 V 加权求和，就是这个词的新表示——它把全句里跟自己最相关的内容都搬了一份进来。因为每个词都同时做这件事，所以任意两个词之间不用像接力赛一样层层传递，一步就到。但这件事本身不认顺序，词序得靠给每个向量加一个「第几位」的记号（位置编码）才能进去。
