# 自注意力：一篇能带走的笔记

**一句话**：自注意力是让每个词向量动态地从全句「按相关性搬运内容」的加权求和机制；它本身不知道顺序，顺序靠位置编码从外部注入。

**为什么需要它**：RNN 里第 1 个词传到第 1000 个词要走 999 步，每一步都在丢信息；注意力让任意两个词一步直达，代价是把 O(n) 的路程换成 O(n²) 的配对计算。序列不太长时，这笔买卖划算。

**机制四步（每步可心算）**：

1. 每个词向量 x 乘三个可学矩阵，得到三份投影：Q（我要找什么）、K（我贴什么标签）、V（我携带什么内容）。
2. 打分：S = QKᵀ，得 n×n 矩阵，S[i][j] = 词 i 觉得词 j 多相关。
3. 归一：除以 √d_k（防止点积过大把 softmax 推进梯度≈0 的饱和区，纯数值工程），再按行 softmax，每行和为 1。
4. 搬运：输出 = 权重 × V，每个词的新表示 = 全句内容的加权和。

**心算一遍**：两个正交的词向量 [1,0,1,0] 和 [0,1,0,1]，单头 d_k=4、投影为单位阵。打分 [[2,0],[0,2]] → 除 2 → softmax → [[0.73,0.27],[0.27,0.73]] → 输出 = 0.73 自己 + 0.27 对方。把两词对调，权重跟着对调、输出跟着对调——顺序信息没有任何变化，这就是必须加位置编码的原因。

**三条边界，判断时必查**：

1. **置换等变**：没有位置编码的注意力处理不了顺序。「狗咬人」和「人咬狗」对它一样。
2. **O(n²) 代价**：序列太长就换稀疏/线性注意力，或先问路径长度 O(1) 值不值。
3. **mask 才因果**：GPT 类模型「只能往前看」来自打分时把未来位置置 -∞，不是注意力天然如此。

**我现在能做的判断/行动**：

- 见到用注意力的模型，先问三件事：序列多长（n² 可接受吗）、位置信息怎么进（有 PE 吗）、要 mask 吗（自回归吗）。三问答完，适用场景就清楚了。
- 能手推 2-token 注意力前向，并能向同事讲清 Q/K/V 和 √d_k。
- 读注意力变体论文时，能按「打分函数 / 缩放 / 位置编码 / mask / 多头」定位它改的是哪个部件——部件对应痛点，痛点来自历史（见视角扩展）。
